# WASH 외부 친구 테스트 배포

이 문서는 `render.yaml`에 정의한 공개 시험용 골조를 설명합니다. 이 파일을 추가하는 것만으로 외부 서비스가 생성되지는 않습니다. 배포 소스는 개인 GitHub 저장소 `huanghua-Habby/Wash-`의 현재 스냅샷입니다.

## 구성

- Render Web Service **한 인스턴스**가 빌드된 게임 페이지와 방 등록·WebSocket 신호 서비스를 함께 제공합니다. 방 정보는 프로세스 메모리에만 있으므로 여러 인스턴스로 늘리면 같은 방을 공유할 수 없습니다.
- 사이트가 HTTPS로 열리면 클라이언트는 같은 주소의 `wss://…/ws`를 사용합니다. 이 경로에는 `VITE_ROOM_WS_URL`이 필요하지 않으며, `npm run package:static`으로 만드는 Game Share ZIP도 사용하지 않습니다.
- `render.yaml`은 `npm ci && npm run build`로 빌드하고 `npm start`로 실행합니다. Render의 `PORT` 환경 변수와 `/health` 확인 경로를 현재 코드가 지원합니다.
- 초기 요금제는 `free`, 자동 배포는 `off`입니다. 무료 인스턴스는 유휴 상태에서 잠들 수 있고, 재시작하거나 수동 배포하면 현재 방 등록이 사라집니다. 안정적인 상시 운영이 필요해지면 요금제를 다시 선택해야 합니다.

## 배포 전에 필요한 정보

1. **게임 리소스의 공개 사용 범위:** 모델·텍스처·음향을 공개 저장소와 공개 게임에서 사용할 수 있는지 확인합니다.
2. **Render 계정:** 계정 생성과 로그인은 소유자가 합니다. 비밀번호나 API 키를 채팅에 보내지 않습니다.
3. **친구들의 대략적인 지역과 예상 동시 인원:** 서버 지역과 요금제를 결정할 때 사용합니다.
4. **개인 도메인(선택):** 처음에는 Render의 `onrender.com` 주소로 확인할 수 있습니다. 이후 `play.내도메인` 같은 하위 주소를 연결할 수 있습니다.
5. **외부 ICE 서비스:** Render는 WASH의 UDP 3478 STUN 포트를 공개하지 않으므로 `WASH_STUN_PORT=0`으로 설정했습니다. 서로 다른 인터넷망의 WebRTC 연결에는 외부 STUN이 필요하고, 직접 연결이 안 되는 조합에는 TURN이 필요합니다. 제공업체와 계정은 실제 친구 테스트 전에 정해야 합니다.

## ICE 연결에서 남은 작업

현재 서버는 `WASH_ICE_SERVERS`에 JSON 형식의 ICE 서버 목록을 넣어 브라우저에 전달할 수 있습니다. STUN 주소만 넣으면 일부 네트워크에서는 연결되지만 모든 환경의 성공을 보장하지 않습니다. TURN 제공업체가 임시 자격 증명을 발급하는 경우, **서버가 자격 증명을 받아 짧게 유효한 값만 브라우저에 전달하도록 코드 연결이 추가로 필요**합니다. 제공업체의 장기 비밀키를 프런트엔드 빌드나 `render.yaml`에 넣지 않습니다.

따라서 현재 골조는 **웹 페이지·방 서버 배포 준비**까지입니다. 원격 WebRTC 플레이가 안정적으로 되는지 확인하기 전에는 배포 성공을 게임 연결 성공으로 해석하지 않습니다.

## 권한과 계정이 준비되면

1. GitHub의 `huanghua-Habby/Wash-`를 Render에 연결하고 **Blueprint**로 `render.yaml`을 읽어 Web Service 하나를 만듭니다. 계정의 요금제와 배포 지역을 확인한 뒤 생성합니다.
2. 처음 받은 `https://….onrender.com/health`가 `ok: true`를 반환하고 게임 페이지가 열리는지 확인합니다. 연결은 `wss://` 같은 주소의 `/ws`로 이뤄집니다.
3. 외부 STUN/TURN을 연결한 뒤, 서로 다른 인터넷망의 친구 두 명 이상이 같은 방에 들어가 실제 플레이하는지 확인합니다. 연결이 실패한 경우 ICE 후보와 실패 사유를 확인합니다.
4. 개인 도메인을 쓰려면 Render의 **Custom Domains**에 하위 도메인을 추가하고, 도메인 제공업체의 DNS 화면에 Render가 안내한 레코드를 등록합니다. Render가 HTTPS 인증서를 발급합니다.
5. 자동 배포가 꺼져 있으므로 새 버전은 수동으로 배포합니다. 배포 중인 방은 종료되므로 플레이 중에는 배포하지 않습니다.

Render 공식 문서: [Blueprint 설정](https://render.com/docs/blueprint-spec), [WebSocket 지원](https://render.com/docs/websocket), [사용자 도메인 연결](https://render.com/docs/custom-domains).
